# Changelog

## 0.1.0

First public version.

- Per-app volume, mute and icons, merged by process name, with the master volume of the active output.
- Output buttons that switch the Windows default playback device, mapped to your own devices in `config.json`.
- Pin apps, reorder them with a grip, and dimmed rows for apps that are not playing.
- Full and compact layouts, highlight color (Windows accent by default, presets or custom) and opacity, from the right-click menu.
- An original helper on the Windows Core Audio API, built with the compiler that ships with Windows.
